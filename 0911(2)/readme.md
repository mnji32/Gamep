## 09월 11일 수업내용

### 1. 입력 버퍼와 줄바꿈 문자
- `fgets()`는 문자열을 입력받을 때 Enter에 해당하는 `\n`까지 저장할 수 있음
- `scanf(" %c", &c)`처럼 `%c` 앞에 공백을 넣으면 입력된 공백이나 줄바꿈 문자를 건너뛰고 실제 문자를 입력받을 수 있음

### 2. ASCII 코드와 scan 코드
* **ASCII 코드**: 문자를 처리하거나 전송하기 위해 사용하는 코드
* **scan 코드**: 키보드의 각각의 키에 대한 코드
* `화살표 키`, `Home`, `End`, `Page Up`, `Page Down` 등은 확장키 코드로 처리
* 확장키가 입력되면 `getch()`를 한 번 더 호출하여 해당 키의 코드를 확인

### 3. 방향키를 이용한 이동
* `getch()`를 이용하여 키보드 입력을 받음
* 방향키의 Scan Code를 이용하여 상, 하, 좌, 우로 이동
* `switch`문을 이용하여 입력된 키에 따라 이동 방향을 결정
* 좌표의 최대값과 최소값을 설정하여 화면 밖으로 이동하지 않도록 처리

### 4. 사각형 그리기
* 텍스트 모드에서 확장 완성형 문자를 이용하여 사각형을 표현
* `─`, `│`, `┌`, `┘` 등의 문자를 이용하여 사각형의 모서리와 선을 표현

### 5. 크기가 다른 정사각형 그리기
* 정사각형의 크기를 사용자에게 입력받음
* 입력받은 크기를 `draw_square()` 함수에 전달
* `for`문을 이용하여 가로와 세로의 길이를 반복해서 출력

### 사용한 주요 함수 및 문법
| 함수 / 문법         | 내용              |
| --------------- | --------------- |
| `fgets()`       | stdin에서 최대 크기만큼 문자열 입력       |
| `getch()`       | 키보드 입력 받기       |
| `gotoxy()`      | 커서 위치 이동        |
| `switch`        | 입력된 키에 따라 동작 결정 |
| `draw_square()` | 정사각형을 그리는 함수    |
