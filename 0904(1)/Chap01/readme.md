## 09월 04일 수업내용

### 1. 커서 위치 제어
* gotoxy() 함수를 이용한 콘솔 커서 위치 이동
* 원하는 위치에 문자 출력

### 2. 화면 지우기
* system("cls")를 이용한 콘솔 화면 지우기
* getch()를 이용한 키보드 입력

### 사용한 주요 함수
| 함수              | 내용       |
| --------------- | -------- |
| gotoxy()      | 커서 위치 이동 |
| system("cls") | 화면 지우기   |
| getch()       | 키보드 입력   |
