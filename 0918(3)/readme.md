### 1. C언어 컴파일 단위 및 대입 문법
#### 1) C언어 컴파일 단위
- C언어의 기본 컴파일 단위 = **파일 (.c)**
- 컴파일러는 독립된 소스 코드 파일 단위로 번역 및 컴파일을 수행

#### 2) 대입문(Assignment Statement)과 표현식(Expression)
대입 연산자(=)를 기준, 좌변에는 변수(L-value), 우변에는 하나의 값으로 평가되는 표현식(R-value)이 위치

- 구조: Assignment = Statement / Variable = Expression

| 표현식종류 | 예시 | 설명 |
| --- | --- | --- |
| Literal (or Constant) | a = 1; | 순수한 고정 데이터 값 대입 |
| Variable | a = b; | 다른 변수의 값을 읽어와서 대입 |
| Operator | a = b + 1; | 연산자를 통해 계산된 결과값 대입 |
| Function | a = sum(1, 2) * 6; | 함수의 반환 값을 연산 후 대입 |

### 2. getch()
| 함수 | 프로토타입/헤더 | 입력스트림/버퍼 |
| **getch()** |	int getch(void); <conio.h> | 키보드 직접 입력 |

#### 1) `# int input = getch() - 48` 에서 **-48**을 하는 이유?
getch() 함수는 키보드로 입력한 숫자 키(예: '1', '2')를 **ASCII 코드값** 형태로 반환
문자 '0'의 ASCII 코드값은 **48**
따라서 입력받은 문자 형태의 숫자를 **실제 정수 값**으로 변환하기 위해 '0'의 ASCII 값인 48을 빼줍니다.

### 4. 난수(Random Number)생성과 시드(Seed) 값
#### 1) 시드(Seed)값의 개념
컴퓨터의 난수는 수학 공식에 의해 계산되는 의사 난수
**시드(Seed)값**은 난수 계산 공식의 **'시작점(기준값)'** 역할을 합니다.
동일한 시드값을 사용하면 매번 동일한 순서의 난수열이 생성됩니다.
#### 2) **시간(time(NULL))**을 시드값으로 사용하는 이유
프로그램 실행 시마다 다른 난수를 얻기 위해 1초 단위로 계속 변하는 '현재 시스템 시간'을 시드값으로 지정
srand((unsigned int)time(NULL)); // 현재 시간을 시드로 설정

### 5. 가변인수
#### 1) 가변인수의 개념
매개변수의 개수와 타입이 확정되지 않은 함수를 정의할 때 사용(예: printf, scanf)

#### 2) 핵심 매크로 4가지
va_list: 가변인자의 메모리 주소를 가리키는 포인터 변수 선언
va_start(ap, last_fixed_arg): 가변 인자를 읽기 위해 포인터를 첫 번째 가변 인자로 초기화
va_arg(ap, type): 현재 위치에서 지정한 타입만큼 데이터를 읽어오고 포인터 이동
va_end(ap): 가변 인수 사용 종료 후 포인터 정리
