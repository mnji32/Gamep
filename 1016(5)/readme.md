## 10월 16일 수업 내용

### 1. 숫자의 변환과 자릿수 처리 (숫자 vs 문자열 출력)

#### 1) 숫자 출력 vs 문자열 출력 비교
숫자 데이터를 화면에 출력할 때 **정수 연산 방식**과 **문자열(ASCII) 방식**의 특징 차이를 이해하고 상황에 맞게 선택

| 구분 | 숫자 (정수 연산) 방식 | 문자열 (배열/ASCII) 방식 |
|:---|:---|:---|
| **입력 방식** | `scanf("%d", &num);` | `scanf("%s", str);` |
| **자릿수 접근** | 산술 연산자 (`/`, `%`) 활용 | 배열 인덱스 (`str[i]`) 및 `strlen()` 활용 |
| **장점** | 추가 메모리 할당이 없고, 수학적 계산이 직관적임 |`int` 범위를 넘어서는 대용량 숫자 처리 가능 |
| **단점** | 높은 자릿수부터 출력 시 나눗셈 단위 계산 로직 필요 | ASCII 코드 변환 (`-'0'`) 연산 필요 |

#### 2) 정수 연산(`/`, `%`)을 이용한 자릿수 추출 원리
- **낮은 단위(일의 자리부터) 역순 출력**: `% 10`으로 일의 자리를 구한 뒤 `/ 10`으로 자릿수를 줄여나감
- **높은 단위(백의 자리부터) 정순 출력**: 대상 숫자보다 한 단계 높은 단위(예: 1000)로 나눈 후 몫과 나머지를 계산

```c
// 예시: 정수를 높은 자릿수부터 출력하는 핵심 로직
int num = 1234;
int divider = 1000;

while (divider > 0) {
    printf("%d ", num / divider); // 가장 높은 자릿수 출력
    num %= divider;               // 남은 숫자 업데이트
    divider /= 10;                // 나누는 단위 축소
}
```

### 2. 일반 재귀 vs 꼬리 재귀 
#### 1) 일반 재귀와 꼬리 재귀 비교
| 구분 | 일반 재귀 | 꼬리 재귀 |
| --- | --- | --- |
| **마지막 연산** | 재귀 호출 결과에 추가 연산 수행 (n * func(...)) | 재귀 호출 자체가 함수의 마지막 연산 |
| **스택 메모리** | 호출할 때마다 스택 프레임이 계속 쌓임 (O(n)) | 컴파일러 최적화 시 스택 프레임을 재활용 (O(1)) |
| **스택 오버플로** | 재귀 깊이가 깊어지면 위험성 커짐 | 꼬리 호출 최적화(TCO) 지원 시 스택 오버플로 방지 |

#### 2) C언어 코드로 보는 차이점
#### ① 일반 재귀
재귀 호출이 돌아온 후 n * 연산을 수행해야 하므로 스택 메모리에 이전 호출 정보가 계속 남습니다.

```c
int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1); // 재귀 호출 후 곱셈 연산 필요
}
```

#### ② 꼬리 재귀
연산 결과(누적값 acc)를 매개변수로 전달하여, 마지막에 추가 연산 없이 함수 자체만 호출하고 종료합니다.

```c
int factorial_tail(int n, int acc) {
    if (n <= 1) return acc;
    return factorial_tail(n - 1, n * acc); // 함수 호출이 마지막 연산
}
```

### 3. 콘솔 좌표 제어와 슬라이드바 구현
#### 1) gotoxy() 함수의 원리와 필요성
콘솔 화면에서 전체 화면을 갱신하지 않고 원하는 위치 (x,y)에만 텍스트/도형을 출력하기 위해 Windows API를 활용합니다.

```c
#include <windows.h>

void gotoxy(int x, int y) {
    COORD Pos = {x - 1, y - 1}; // 콘솔 좌표계(0부터 시작)에 맞게 조정
    SetConsoleCursorPosition(GetStdHandle(STD_OUTPUT_HANDLE), Pos);
}
```

#### 2) 방향키 입력을 통한 슬라이드바 제어
특수문자(■)를 사용하여 슬라이드바의 차오르는 형태(수평/수직)를 표현합니다.
키보드 방향키 입력을 받아 좌표 변수 (x,y)를 증가/감소시킨 후 gotoxy()로 슬라이드바의 길이 및 화살표 위치를 이동시킵니다.
