카페 생존일지 : 알바생의 하루 — 업그레이드 프롬프트 30개

==================================================
Part 1. 코드 진단 & 코어 (7개)
==================================================

#01 [현황 분석]
지금 코드를 처음부터 끝까지 단계별로 읽고, 문제점을 '버그 / 구조 / 사용성' 세 가지로 나눠서 표로 정리해 줘. 코드는 아직 고치지 마.

#02 [버그 우선 수정]
방금 표에서 찾은 버그만 먼저 고쳐 줘. 각 버그를 왜 그렇게 고쳤는지 한 줄씩 설명해 줘.

#03 [코드 리팩토링]
기능은 하나도 바꾸지 말고, 전역 변수를 정리하고 함수를 역할별로 나눠서 코드를 읽기 쉽게 리팩토링해 줘.

#04 [조작 방식 변경]
클릭 두 번 대신 드래그로 합치게 바꿔 줘. 마우스와 모바일 터치 둘 다 자연스럽게 작동하게 해 줘.
드래그로 하니 손목 피로도가 너무 높아서 터치 형식으로 바꿀게. 첫 번째 터치 시 해당 칸 테두리가 뚜렷하게 빛나서 '현재 선택된 아이템'임을 알 수 있게 표시하고, 같은 칸을 다시 터치하면 선택이 취소되도록 예외 처리해줘.

#05 [보드 확장]
보드를 8x8로 키우고, 게임을 시작하면 64칸이 1단계 랜덤 재료들로 꽉 차 있게 해 줘.

#06 [메뉴 트리 구축]
메뉴 트리를 늘려 줘. 규칙은 '같은 거 2개 = 다음 단계' 하나만 쓰고, 음료는 음료끼리, 디저트는 디저트끼리만 진화하게 아래 4줄(1~5단계)로 정확히 만들어 줘.
- 커피(음료): 커피 원두 -> 에스프레소 -> 아메리카노 -> 카페라떼 -> 아인슈페너
- 녹차(음료): 녹차 잎 -> 찻잎 우림 -> 녹차 -> 녹차 라떼 -> 녹차 프라페
- 복숭아(음료): 복숭아 -> 복숭아청 -> 아이스티 -> 스무디 -> 버블티
- 밀가루(디저트): 밀가루 -> 빵 반죽 -> 소금빵 -> 와플 -> 조각 케이크

#07 [판매 메뉴 구분]
3단계부터는 손님에게 팔 수 있는 완성 메뉴니까, 테두리 색을 다르게 해서 재료와 한눈에 구분되게 해 줘.

==================================================
Part 2. 손님 주문 & 서빙 (7개)
==================================================

#08 [다중 손님 주문]
손님이 최대 3명까지 동시에 오게 해 줘. 각 손님은 음료 1개, 또는 음료 + 디저트 조합을 주문하게 해 줘.

#09 [손님 대기 시간]
손님마다 2분 대기 시간을 만들고 남은 시간을 벽시계 모양으로 보여 줘. 시간이 다 되면 손님이 화나서 나가게 해 줘.

#10 [서빙 · 오주문 방지]
'주기' 버튼을 없애고, 완성된 메뉴를 손님 칸으로 직접 드래그해서 주는 방식으로 바꿔 줘. 주문과 다른 메뉴를 주면 거절하게 해 줘.

#11 [손님 자동 충원]
손님이 서빙을 받거나 화나서 나가면 빈자리가 오래 비어 있지 않게 바로 다음 손님이 들어오게 해 줘.

#12 [주문 손님 강조]
손님이 원하는 메뉴를 완성했을 때, 그 메뉴를 주문한 손님 카드를 바로 알 수 있게 시각적 포인트(강조 표시)를 줘.

#13 [재료 상자 · 휴지통]
'재료 받기' 버튼을 '재료 상자'로 바꾸고, 보드가 막혔을 때 필요 없는 재료를 드래그해서 버릴 수 있는 휴지통을 만들어 줘.

#14 [합칠 칸 강조]
플레이해 보니 뭘 합쳐야 할지 헷갈려. 아이템을 드래그하는 동안 보드 위에서 합칠 수 있는 같은 아이템 칸을 반짝이게 해 줘.

==================================================
Part 3. 점수 & 밸런스 (4개)
==================================================

#15 [차등 점수]
점수를 메뉴 단계별로 다르게 줘. 높은 단계 메뉴일수록 기본 점수가 크고, 손님 대기 시간이 많이 남은 상태에서 빨리 줄수록 보너스 점수가 붙게 해 줘.

#16 [하트 시스템]
생명창(하트) 3개를 만들어 줘. 손님이 화나서 나갈 때마다 하트가 하나씩 줄어들고, 3개가 다 없어지면 게임 오버가 되게 해 줘.

#17 [제한 시간 · 등급]
전체 제한 시간 3분을 만들어 줘. 3분 동안 버티면 최종 점수에 따라 S / A / B / C 등급이 나오는 결과창을 보여 줘.

#18 [수치 기반 밸런스]
지금 밸런스가 적당한지 모르겠어. 메뉴 하나 만드는 데 평균 몇 번 합쳐야 하는지, 3분 동안 손님을 최대 몇 명 받을 수 있는지 단계별로 계산해 보고, 그 계산을 근거로 S/A/B/C 등급 기준 점수와 재료 상자 드롭 확률을 정해서 적용해 줘.

==================================================
Part 4. 세계관 & 연출 (8개)
==================================================

#19 [도트 디자인]
게임 디자인을 귀여운 도트(픽셀) 그래픽 컨셉으로 전면 수정해 줘. 전체 글씨 크기를 키워 가독성을 높이고, 모든 재료와 완성 메뉴에 직관적인 귀여운 도트/이모지 아이콘을 적용해 줘.

#20 [토끼 알바생 패널]
게임 이름은 '카페 생존일지', 알바생 캐릭터는 토끼로 설정해 줘. 화면 옆에 알바생 캐릭터 패널을 만들고, 평소엔 랜덤 혼잣말 말풍선을 띄우다가 메뉴 완성, 서빙 성공, 손님 분노 시에는 현재 알바생의 애환이 담긴 현실 공감 대사가 나오게 해 줘.

#21 [BGM · 효과음]
카페 분위기에 맞는 기본 게임 BGM을 하나 넣어 줘. 그리고 합치기, 서빙 성공, 손님 화남, 게임 오버 상황마다 어울리는 효과음(Web Audio API 활용)을 넣어 줘.

#22 [동물 손님 12명]
손님을 동물 캐릭터 12명(고양이, 강아지, 개구리, 부엉이, 토끼, 곰, 펭귄, 돼지, 기니피그, 햄스터, 병아리, 나무늘보)으로 만들고 각자 이름을 붙여 줘. 손님 머리 위에 말풍선을 띄우고, 기다린 시간이 길어질수록 대사가 점점 조급해지게 유머러스하게 작성해 줘.

#23 [타격감 연출]
서빙 시 점수가 위로 떠오르는 효과, 손님이 화날 때 좌우로 흔들리는 쉐이크 효과를 넣어 줘.

#24 [손님 카드 수집]
만족한 손님이 서빙을 받고 갈 때 일정 확률로 자기 명함(카드)을 두고 가는 '카드 수집' 기능을 만들어 줘. 카드에는 손님 얼굴, 이름, 간단한 소개, 최애 메뉴가 들어가고, 새 게임을 시작할 때마다 수집 목록은 초기화되게 해 줘.

#25 [보너스 미션]
플레이 중 지루하지 않게 달성하기 쉬운 실시간 보너스 미션(예: '15초 안에 음료 1잔 서빙', '3연속 합치기')을 띄워 주고, 성공하면 추가 점수를 주게 해 줘.

#26 [레시피북]
레시피를 외우기 힘드니까 '레시피북' 버튼을 누르면 전체 조합표가 팝업으로 열리게 하고, 레시피북이 열려 있는 동안에는 게임 시간과 손님 시간이 멈추게 해 줘.

==================================================
Part 5. 게임 흐름 완성 (4개)
==================================================

#27 [이름 입력 · 로비]
게임을 켜면 먼저 플레이어(알바생) 이름을 입력받고, 이후 메인 시작 화면으로 넘어가게 해 줘. 시작 화면에는 간단한 규칙 설명과 '게임 시작', '레시피 보기', '순위 보기' 버튼을 배치해 줘.

#28 [일시정지 · F등급]
플레이 중 일시정지 버튼을 누르면 손님 시간과 플레이 시간이 모두 멈추고 '계속하기', '재시작하기', '그만하기' 팝업이 뜨게 해 줘. '그만하기'를 누르면 즉시 게임 실패와 함께 최종 F등급 결과창으로 넘어가게 해 줘.

#29 [최고 점수 · 순위]
플레이한 점수들을 현재 브라우저 세션에 저장해서 시작 화면의 '순위 보기'와 결과창에 최고 점수를 보여 줘. 브라우저를 껐다 켜면 초기화되게 하고, 최고 기록을 경신하면 결과창에 축하 표시를 띄워 줘.

#30 [결과창 동선]
결과 화면(S/A/B/C/F등급)에 '확인' 버튼과 '재시작' 버튼을 넣어 줘. '확인'을 누르면 시작 화면(로비)으로 돌아가고, '재시작'을 누르면 같은 이름으로 즉시 새 게임이 시작되게 연결해 줘.
