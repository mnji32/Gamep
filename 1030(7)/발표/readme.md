# 🎮 C언어 콘솔 보물찾기 게임 (Treasure Hunt Game)

> C언어 기반의 텍스트 콘솔 보물찾기 게임입니다. 기존 기본 원본 코드를 기반으로 버그 수정, 화면 개선, 게임 요소 및 효과음을 추가하여 총 30가지 기능 업그레이드를 완료하였습니다.

---

## 📌 주요 특징
* **다양한 조작 방식 지원**: 방향키 및 WASD 이동 지원
* **실시간 HUD 시스템**: 좌표, 이동 횟수, 보물 수집 현황 상시 표시
* **사운드 효과음**: Windows API `Beep()` 기반 효과음 적용
* **게임성 강화**: 무작위 함정, 거리 계산 힌트(3회 제한), 3초 카운트다운 연출

---

## 📊 업그레이드 내역 (총 30가지 개선 사항)

| 번호 | 개선 및 추가 기능 | 주요 구현 내용 |
| :---: | :--- | :--- |
| **1** | 맵 배열 크기 안정화 | 10x10 격자 배열 경계 에러 방지 및 1-indexed 좌표 매핑 |
| **2** | 맵 간격 및 레이아웃 개선 | 콘솔 2:1 문자 비율을 고려한 `gotoxy()` x좌표 2칸 이동 정밀화 |
| **3** | 보물 위치 중복 생성 방지 | `do-while` 난수 검사 로직을 도입하여 보물 상호 중복 방지 |
| **4** | 표준 클럭 적용 | `CLOCKS_PER_SEC`을 적용하여 시스템 전역 표준 소요 시간 측정 |
| **5** | 소스코드 최적화 | 미사용 변수 제거 및 함수 구조 모듈화 |
| **6** | 확장 방향키 입력 처리 | Windows 콘솔 특유의 확장 키(-32) 2바이트 버퍼 안정적 처리 |
| **7** | 메인 메뉴 시스템 | 게임 시작, 게임 설명, 게임 종료 분기 선택 메인 화면 구별 |
| **8** | 실시간 상단 HUD 구축 | 플레이 화면 상단에 좌표, 턴 제한, 보물 개수를 고정 표시 |
| **9** | 플레이어 시각화 | 플레이어 위치 심볼(`&`) 및 이동 흔적(`■`) 시각 갱신 |
| **10** | 콘솔 텍스트 색상 적용 | `SetConsoleTextAttribute` 기반의 가독성 높은 색상 연출 |
| **11** | 승리 / 패배 결과 리포트 | 게임 종료 시 탐험 소요 시간, 턴 수, 점수 종합 연출 화면 |
| **12** | 최단거리 힌트 시스템 | 맨하탄 거리 알고리즘($\vert X_1 - X_2 \vert + \vert Y_1 - Y_2 \vert$) 기반 H키 힌트 제공 |
| **13** | Beep sound 효과음 | 게임 시작, 보물 발견, 승리, 패배, 힌트 사용 시 Sound 재생 |
| **14** | 재시작 및 종료 선택 | 게임 클리어/오버 후 R(재시작), Q(종료) 루프 시스템 |
| **15** | 최종 점수 산출 공식 | `(남은 이동 턴 × 20점) - (소요 시간 × 2점)` 결과 SCORE 산출 |
| **16** | WASD 다중 조작 지원 | 방향키 외에 Standard WASD 키 입력을 동시 조작 지원 |
| **17** | ESC 일시정지 메뉴 | 게임 진행 도중 ESC 키로 일시 정지 및 게임 종료 기능 구현 |
| **18** | 최대 이동 제한 설정 | 65회 이동 턴 제한 설정 및 소진 시 GAME OVER 로직 구현 |
| **19** | 무작위 함정 시스템 | 맵 무작위 배치 함정(X) 및 밟을 시 3초간 이동 불가 패널티 |
| **20** | 보물 수집 확장 | 보물 개수를 기존 2개에서 3개로 확장하고 난이도 개편 |
| **21** | 콘솔 커서 숨김 처리 | `CONSOLE_CURSOR_INFO`를 적용하여 깜빡이는 텍스트 커서 제거 |
| **22** | 기호 및 맵 비주얼 정밀화 | 맵 요소별 시각적 기호(■, ★, X, &) 및 개별 색상 매핑 |
| **23** | 상시 조작 가이드 표시 | 하단 고정 조작 안내선 배치 |
| **24** | 잘못된 키 예외 처리 | 허용되지 않은 키 입력 시 하단 경고 메시지 출력 및 무효화 |
| **25** | 실시간 보물 카운터 | 찾은 보물 개수 및 남은 보물 개수 즉시 갱신 |
| **26** | 시간 분/초 단위 환산 | 소요 시간(초)을 `X분 Y초` 직관적 단위로 분할 출력 |
| **27** | 무효 이동 턴 차감 방지 | 벽에 부딪히거나 외곽으로 이동 시 이동 횟수가 증가하지 않도록 보정 |
| **28** | 시작전 카운트다운 연출 | 게임 시작 전 `3.. 2.. 1.. START!` 시각 및 청각 연출 |
| **29** | 플레이어 실시간 좌표 추적 | 1행 HUD에 플레이어 현재 격자 좌표 `(X, Y)` 표시 |
| **30** | 힌트 사용 횟수 제한 로직 | 무분별한 힌트 남발 방지를 위한 판당 최대 3회 힌트 사용 제한 |

## ⚙️ 실행 및 빌드 환경
* **OS**: Windows (Visual Studio, Dev-C++, MinGW 컴파일 환경)
* **언어**: C (C99 이상 권장)
* **헤더**: `<windows.h>`, `<conio.h>`, `<time.h>`, `<stdlib.h>`, `<stdio.h>`
