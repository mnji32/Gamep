# 🎮 C언어 콘솔 보물찾기 게임 (Treasure Hunt Game)

> C언어 기반의 텍스트 콘솔 보물찾기 게임입니다. 기존 기본 원본 코드를 기반으로 버그 수정, 화면 개선, 게임 요소 및 효과음을 추가하여 총 30가지 기능 업그레이드를 완료하였습니다.

---

## 📌 주요 특징
* **다양한 조작 방식 지원**: 방향키 및 WASD 이동 지원
* **실시간 HUD 시스템**: 좌표, 이동 횟수, 보물 수집 현황 상시 표시
* **사운드 효과음**: Windows API `Beep()` 기반 효과음 적용
* **게임성 강화**: 무작위 함정, 거리 계산 힌트(3회 제한), 3초 카운트다운 연출

---


## ⚙️ 실행 및 빌드 환경
* **OS**: Windows (Visual Studio, Dev-C++, MinGW 컴파일 환경)
* **언어**: C (C99 이상 권장)
* **헤더**: `<windows.h>`, `<conio.h>`, `<time.h>`, `<stdlib.h>`, `<stdio.h>`
