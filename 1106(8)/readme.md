# 🏴‍☠️ 보물 찾기 게임 Ver 2.0

> C언어 콘솔 게임 **응용 8-7-1 코드**를 분석하고, 문제점을 고치면서 **30가지 업그레이드**를 적용한 프로젝트

## 🎮 게임 소개

10×10 격자 안에 숨겨진 보물을 찾는 콘솔 게임

| | 원본 | **Ver 2.0** |
|---|---|---|
| 코드 / 함수 | 157줄 / 7개 | **604줄 / 13개** |
| 보물 · 함정 · 힌트 | 2개 · 없음 · 없음 | **3개 · 2개 · 3회** |
| 이동 제한 | 없음 | **75회** |
| 결과 | 경과 시간만 출력 | **점수 · 등급 리포트, R 재시작 / Q 종료** |

## 🕹 조작법 & 규칙

| 키 | 동작 |
|---|---|
| `방향키` / `WASD` | 이동 |
| `H` | 힌트 (남은 보물까지 거리, 최대 3회) |
| `ESC` | 일시정지 |
| `R` / `Q` | 재시작 / 종료 |

- **맵 기호:** `&` 플레이어 · `□` 지나온 칸 · `★` 찾은 보물 · `X` 함정 (밟으면 3초 정지)
- **점수:** `(남은 이동 횟수 × 20) − (소요 시간(초) × 2)`
- **등급:** S+ 1,100↑ · S 850↑ · A 500↑ · B 500 미만 · F 보물 3개 미발견

## 🐞 원본 코드의 문제점 (14가지)

**치명적 문제**
1. 좌우 이동 시 2칸씩 이동 → 맵 밖으로 이탈
2. 보물 좌표 중복 → 게임이 끝나지 않는 무한 루프
3. 좌표 범위 오류 → 1행·1열에는 보물이 생기지 않음

**그 밖의 문제**
- **동작:** 방향키 이중 입력, 매 입력마다 맵 전체 재출력, 구형 `CLK_TCK`, 현재 위치 표시 없음
- **구조:** 화면 좌표·배열 인덱스 혼재, 선언·정의 배열 크기 불일치, 미사용 코드, 100칸 전수 조사
- **사용성:** Windows 전용, 커서 깜빡임, ESC·재시작·이동 제한 없음
